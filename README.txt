
SPINNING WHEEL WEBSITE
======================

HOW TO OPEN THE PROJECT
-----------------------

1. Open the Spinning-Wheel folder in Visual Studio Code.
2. Make sure all four project files are inside the folder.
3. Install the Live Server extension if it is not already installed.
4. Right-click index.html.
5. Select Open with Live Server.

HOW TO USE
----------

1. Add entries in the Wheel Entries section.
2. Edit or delete entries using the buttons beside each entry.
3. Choose a spinning duration.
4. Click SPIN NOW.
5. The wheel will select one random entry.
6. Close the result popup using OK, X, or by clicking outside it.
7. The selected entry will then be removed from the wheel.

MUSIC AND SOUND
---------------

1. Upload a background music file.
2. Click Play music to start the background music.
3. You may also upload an optional spinning sound.
4. You may upload an optional result popup sound.
5. Adjust each volume independently.

SAVING
------

Entries and settings are saved in the browser's Local Storage.
Uploaded audio files are saved in IndexedDB.

The saved information is available in the same browser and on
the same device. Clearing browser site data may delete it.

NOTES
-----

- At least two entries are required to spin.
- A maximum of 100 entries is supported.
- The selected entry is removed only after the result popup closes.
- The Restore Default button restores the original six entries.
- No server or paid software is required.
